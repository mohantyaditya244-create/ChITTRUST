# ChitTrust Professional Menu Update

The dashboard is now organized as separate selectable workspace tabs:

- Dashboard
- Transactions
- Financial Health
- Members
- Hash-Linked Ledger
- Integrity Verification
- Audit Log
- Reports & Evidence

The existing FastAPI backend, database structure, transaction hashing, evidence handling,
member-edit API, audit log, and verification API are retained. The change is primarily
a professional navigation/UI restructuring so each major architecture component has its
own interface.
